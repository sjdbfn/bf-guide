# Betaflight 9 步上手

Betaflight Configurator 从插上 USB 到能起飞的 9 屏顺序导览，按真实截图逐屏写：这一页为什么存在、看图该看哪几处、要动手改什么、哪里容易出事。

- 机型：SpeedyBee F405 V3（STM32F405）
- 固件：Betaflight 4.5.2
- 配置器：Betaflight Configurator 2026.6.2 (091127c)

## 在线打开

部署到 GitHub Pages 后直接访问仓库主页地址即可，例如
`https://<你的用户名>.github.io/<仓库名>/`

## 本地打开

双击 `index.html`。图片已经打包进这个文件，不需要其它文件、不需要联网、不需要服务器。

## 内容

9 屏依次是：欢迎页 → 传感器 → 端口 → 配置 → PID 调参 → 接收机 → 模式 → 电机 → OSD，
最后附 6 条起飞前必查项。

每屏固定三块：**看图找这几处**（截图上的真实数值）、**动手做**（按顺序的动作）、**别踩的坑**（容易翻车的地方）。

## 说明

截图来自本机实际配置界面，参数仅对应上述机型与固件版本；换机架、换固件后请以自己的界面为准。
